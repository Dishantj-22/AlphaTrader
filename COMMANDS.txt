#  SECTION 15 — SIGNAL MEANINGS
# ================================================================

#  [++]  STRONG BUY   >= 80% confidence   Very high conviction bullish
#  [ +]  BUY          >= 65% confidence   Clear bullish setup
#  [ ~]  WEAK BUY     >= 55% confidence   Mild bullish, smaller size
#  [ =]  HOLD         45-55% confidence   No edge, stay out
#  [ v]  WEAK SELL    35-45% confidence   Mild bearish
#  [ -]  SELL         <= 35% confidence   Clear bearish setup
#  [--]  STRONG SELL  <= 20% confidence   Very high conviction bearish
#  [!!]  BLOCKED       0% confidence      Earnings/event in next 3 days


# ================================================================
#  SECTION 16 — MARKET REGIME MEANINGS
# ================================================================

#  [^^] BULL     — Nifty above EMA200, VIX < 14
#                  Trade at full size, normal threshold (55%+)

#  [--] NEUTRAL  — Nifty near EMA200, VIX 14-18
#                  Trade at 75% size, threshold 60%+

#  [!-] CAUTION  — VIX 18-22 OR Nifty 2-5% below EMA200
#                  Trade at 50% size, threshold 65%+

#  [vv] BEAR     — VIX > 22 OR Nifty > 5% below EMA200
#                  Trade at 25% size, SELL signals only, threshold 70%+
